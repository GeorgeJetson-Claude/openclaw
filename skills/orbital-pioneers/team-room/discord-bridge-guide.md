# Discord Bridge for Orbital Pioneers Team (Recommended for Real-Time Chat with Claude)

## Why Discord?

The Team Room + Drive is excellent for long-term memory and structured updates.

Discord gives you, Claude, and the agents a **real-time group chat** so Claude can quickly say “I just dropped new Ep2 script sections in Drive” and everyone sees it instantly.

## Recommended Discord Server Structure

Create one private server called **Orbital Pioneers Core Team**

**Channels:**

- `#general` — Main ongoing chat (you + Claude + key agents)
- `#drive-pings` — Dedicated channel for Claude (and agents) to post when they add major things to Drive
- `#production` — Episode production discussion
- `#revenue` — Money, merch, eBooks, affiliates
- `#agent-sync` — Broadcasts and coordination (equivalent to @all-agents)
- `#voice` (optional) — For actual calls if needed

## How Claude Should Use It

When Claude adds something important to Drive, he posts in `#drive-pings`:

```
📥 Drive Update

Added: Updated Ep2 script + new villain beats in Universe Bible
Links: [paste Drive links]
Summary: Strengthened the emotional beat at the wings handover and added two new Rumble gags.

@all-agents — read the latest before next cycle.
```

This is the equivalent of the `claude-drive-ping.lobster` workflow but in real time.

1. Create the Discord server (private).
