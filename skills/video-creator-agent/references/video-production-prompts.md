# Reel — Video Production Prompts & Templates

This is the prompt library Reel uses for fast, high-quality cartoon video creation.

## Core Style Rules (Always Follow)

- 90s Saturday morning cartoon aesthetic (thick black outlines, flat vibrant colors, no gradients, expressive faces, limited animation where smart)
- Warm, fun, energetic — never dark or realistic
- Clear 90s cartoon timing and pacing

---

## DaVinci Resolve / CapCut Assembly Prompts

**General Episode Assembly Prompt (use as base):**

"Assemble a full [runtime] episode of Orbital Pioneers in 90s cartoon style.

Use these assets:

- Voiceover tracks: [list files + timing]
- SFX and music: [list files]
- Visual panels/storyboards: [folder or list]
- Character animation layers: [if available]

Requirements:

- Sync dialogue perfectly to mouth flaps where possible (or use smart limited animation)
- Add 90s-style transitions, wipes, and impact frames
- Keep energy high and fun
- Match the emotional beats from the script
- Export two versions: 9:16 vertical (YouTube Shorts optimized) and 16:9 horizontal (website player)

Prioritize speed and charm over perfect frame-by-frame animation."

## YouTube Upload + Ad Prep Prompts

**Title + Description + Tags Generator:**

"Write 5 strong YouTube title options, a full description with timestamps, chapters, links, and end screen CTA, plus 30-50 tags for this Orbital Pioneers episode. Optimize for both search and suggested video traffic. Include the Cali the Husky running gag mention naturally."

**YouTube Ad Script / Creative Brief:**

"Create 3 different 15-30 second YouTube ad concepts for this episode. One action-focused, one emotional/family-focused, one funny/Cali-focused. Include hook, key visuals, voiceover, and CTA. Make them ready for ad approval."

---

## Fast 20-Minute Episode Strategy (When Needed)

When the team wants a full ~20 minute episode instead of shorts:

1. Use the full script + all voice tracks
2. Prioritize limited animation + smart cuts over full animation
3. Reuse backgrounds and character poses where possible
4. Focus on strong dialogue scenes + key action moments
5. Add "previously on" recap + strong cold open + cliffhanger
6. Render in batches if needed

Reel should flag any sections that would benefit from extra human polish by George.

---

**Rule for Reel:** Speed first, charm second, perfection third. We can always do a "director's cut" later. Ship the cartoon.
